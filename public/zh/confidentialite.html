隐私政策

依据欧盟第2016/679号条例（GDPR）第12至14条及法国1978年1月6日第78-17号《信息与自由法》提供的信息。

最后更新: 2026年11月15日

简要说明

  • 无账户、无表单、无广告、无访问统计：本网站不会要求您提供任何个人数据。
  • 本网站不设置任何 Cookie。
  • 市场数据和标志由我们的服务器获取：您的 IP 地址不会发送给数据提供商或标志来源网站。
  • 只有在您接受的情况下，TradingView 图表才会向第三方传输数据。未经您同意，图表不会加载。

数据控制者

数据控制者为本网站发布者（见法律声明）。根据 GDPR 第37条，发布者无须指定数据保护官（DPO）。

接收方

  • Vercel Inc.（托管商），作为发布者的托管处理者。Vercel 也可能根据其隐私声明为自身目的处理部分技术数据。

任何数据都不会出于商业或广告目的出售、出租或转让。

向欧盟以外地区的传输

  • Vercel Inc. 位于美国，声明已加入欧盟—美国数据隐私框架（EU-U.S. Data Privacy Framework），该框架获欧盟委员会2023年7月10日充分性决定认可（GDPR 第45条）。
  • TradingView（如您接受）主要位于美国；其传输所适用的保障措施见其隐私政策。

您的权利

您享有访问、更正、删除、限制处理、反对处理和数据可携带的权利，以及随时撤回同意、并就您身后的数据处置作出指示的权利（GDPR 第15至22条，《信息与自由法》第85条）。

如需行使上述权利，请向本网站发布者提出请求。我们将在一个月内答复，必要时可延长两个月（GDPR 第12条）。由于本网站不管理任何账户，发布者通常不持有可识别您身份的数据（GDPR 第11条）。

您可在Cookie 设置页面一键撤回对 TradingView 的同意。存储在您设备上的数据可通过浏览器设置（网站数据）删除。

安全

本网站仅通过 HTTPS 提供服务（已启用 HSTS），并采用严格的内容安全策略（CSP）。网站没有表单、账户或密码。网站的 API 为只读，不接收任何个人数据，且无法被第三方网站调用。

未成年人

本网站不收集任何需要父母同意的数据。需征得同意的 TradingView 图表面向15岁及以上人士，或经监护人授权者（《信息与自由法》第45条）。
