隐私政策

依据欧盟第2016/679号条例（GDPR）第12至14条及法国1978年1月6日第78-17号《信息与自由法》提供的信息。

最后更新: 2026年11月15日

简要说明

  • 无账户、无注册、无广告、无访问统计：本网站不会要求您提供姓名、电子邮件或任何身份信息。
  • 本网站不设置任何 Cookie。您的自选、设置和模拟账户保存在您的设备上。
  • 市场数据和标志由我们的服务器获取：您的 IP 地址不会发送给数据提供商或标志来源网站。
  • 在您接受的情况下，TradingView 图表会向第三方传输数据。未经您同意，图表不会加载。
  • 如您创建价格提醒，浏览器的通知订阅地址和您的提醒将存储在位于欧盟的服务器上，仅用于通知您。您可随时全部删除（详情）。

数据控制者

数据控制者为本网站发布者（见法律声明）。根据 GDPR 第37条，发布者无须指定数据保护官（DPO）。

价格提醒

提醒为可选功能：在您创建提醒之前，不会向提醒服务器发送任何数据。创建第一个提醒时，浏览器会请求显示通知的权限，然后为本网站创建专用的订阅地址；该地址、相关加密密钥和您的提醒会被存储，以便服务器检查价格（约每 5 分钟一次）并通知您。

每个提醒只触发一次：发送通知后即停用。通知送达无法保证（数据源有时延迟，取决于浏览器推送服务）；提醒绝不构成投资建议。

接收方

  • Vercel Inc.（托管商），作为发布者的托管处理者。Vercel 也可能根据其隐私声明为自身目的处理部分技术数据。
  • Supabase Pte. Ltd.，作为发布者的处理者，用于存储和检查价格提醒（数据存放于欧盟巴黎区域）。见其数据处理协议及隐私政策。
  • 您浏览器的推送服务（例如 Chrome 和 Android 使用 Google，Safari 和 iPhone 使用 Apple，Firefox 使用 Mozilla，Edge 使用 Microsoft），仅在您创建提醒时：负责将通知送达您的设备。通知内容经端到端加密（RFC 8291），推送服务无法读取。
  • TradingView，仅在您接受显示图表时，作为独立的数据控制者（TradingView 隐私政策）。

任何数据都不会出于商业或广告目的出售、出租或转让。

向欧盟以外地区的传输

  • Vercel Inc. 位于美国，声明已加入欧盟—美国数据隐私框架（EU-U.S. Data Privacy Framework），该框架获欧盟委员会2023年7月10日充分性决定认可（GDPR 第45条）。
  • TradingView（如您接受）主要位于美国；其传输所适用的保障措施见其隐私政策。
  • Supabase Pte. Ltd. 位于新加坡。提醒数据存放于欧盟；对于向欧盟以外的传输，其数据处理协议规定适用欧盟委员会标准合同条款（第(EU) 2021/914号实施决定，GDPR 第46条）。
  • 浏览器推送服务可能位于欧盟以外；它们只接收订阅地址和加密通知。

您的权利

您享有访问、更正、删除、限制处理、反对处理和数据可携带的权利，以及随时撤回同意、并就您身后的数据处置作出指示的权利（GDPR 第15至22条，《信息与自由法》第85条）。

如需行使上述权利，请向本网站发布者提出请求。我们将在一个月内答复，必要时可延长两个月（GDPR 第12条）。由于本网站不管理任何账户，发布者通常不持有可识别您身份的数据（GDPR 第11条）。

对于价格提醒，您可随时在“自选”标签页中自行查看和删除，或通过“全部删除并关闭通知”按钮删除全部内容（提醒和设备）。您也可以在浏览器设置中撤销通知权限。

您可在Cookie 设置页面一键撤回对 TradingView 的同意。存储在您设备上的数据可通过浏览器设置（网站数据）删除。

安全

本网站仅通过 HTTPS 提供服务（已启用 HSTS），并采用严格的内容安全策略（CSP）。网站没有账户或密码。除价格提醒中转接口外，网站的 API 均为只读，且无法被第三方网站调用。对于提醒，设备通过随机标识符识别，服务器只保存其指纹；通知经端到端加密；服务密钥保存在加密保险库（Supabase Vault）中。

未成年人

本网站不收集任何需要父母同意的数据。需征得同意的 TradingView 图表面向15岁及以上人士，或经监护人授权者（《信息与自由法》第45条）。
