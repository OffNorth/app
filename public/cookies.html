Sans choix de votre part, aucun graphique TradingView n’est chargé. Votre choix, accord comme refus, est conservé 6 mois sur votre appareil, puis vous sera redemandé. La simple navigation sur le site ne vaut jamais accord.

Ce que dépose le site

Le site ne dépose aucun cookie. Il utilise uniquement le stockage local de votre navigateur, pour des usages strictement nécessaires au service que vous demandez. Ces usages sont exemptés de consentement :

Effacer les données de votre appareil

Retirer votre accord empêche tout nouveau chargement de TradingView. Les données déjà enregistrées par TradingView ou par le site sur votre appareil s’effacent depuis les réglages de votre navigateur : par exemple, « Effacer les données de navigation » sur Chrome (Android), ou Réglages → Safari → Avancé → Données de sites web sur iPhone.
